# 原神风格成就生成器

自定义成就标题与图标，生成原神风格的成就提示图片。

## 功能

- 自定义成就标题，长标题自动缩小
- 多种预设图标，支持单个 Emoji 金色渐变图标
- 实时预览、高清预览与大图查看
- 968 × 280 / 1936 × 560 透明 PNG 导出，默认使用小尺寸
- 可拖动预览图作为成品使用；桌面软件兼容性各异，不支持时请先下载
- 导入自定义 PNG/JPG/WebP 图标（最多 10 MB），自动缩至最长边 384 像素并保存在当前浏览器；请提供风格相符的素材，网页不会自动转换风格
- 适配手机与桌面，纯前端处理，无需上传素材

## 使用

在线使用：[原神风格成就生成器](https://polecj.github.io/Genshin-style-Achievements/)（启用 GitHub Pages 后生效）。

下载项目后，用浏览器打开 [index.html](index.html)，即可离线使用，无需安装依赖或启动服务器。

也可在仓库的 **Settings → Pages** 中启用 GitHub Pages，发布为在线工具。

自定义素材不会上传服务器。下次使用同一浏览器、同一网址可恢复；清除网站数据、无痕模式或浏览器清理存储可能导致素材丢失，请保留原文件。
